# PDFHub - เว็บแอปพลิเคชันแปลงและจัดการไฟล์ PDF แบบ iLovePDF

**PDFHub** คือเว็บแอปพลิเคชันสำหรับจัดการและแปลงไฟล์ PDF แบบครบวงจรที่ได้แรงบันดาลใจจาก iLovePDF โดยเน้นจุดเด่นสำคัญที่สุดคือ **ความปลอดภัยและความเป็นส่วนตัว 100% (Client-Side Processing)** — ทุกไฟล์จะถูกแปลงและประมวลผลภายในเว็บเบราว์เซอร์บนเครื่องของผู้ใช้โดยตรง ไม่มีการอัปโหลดไฟล์ขึ้นเซิร์ฟเวอร์หรือคลาวด์ภายนอก

---

## 🚀 ฟีเจอร์หลัก (Features)

### 1. จัดการและจัดระเบียบไฟล์ (Organize)
- **รวมไฟล์ PDF (Merge PDF):** รวมหลายไฟล์เข้าด้วยกัน สามารถสลับลำดับไฟล์ขึ้น-ลง และลบไฟล์ที่ไม่ต้องการก่อนรวมได้
- **แยกหน้า PDF (Split PDF):** เลือกช่วงหน้าที่ต้องการ (เช่น `1-3, 5, 8`) หรือแตกทุกหน้าเป็นไฟล์ PDF แยกต่างหากในไฟล์ ZIP
- **หมุนหน้า PDF (Rotate PDF):** หมุนหน้าเอกสาร 90°, 180°, 270° ทั้งเอกสารพร้อมกัน หรือหมุนเฉพาะหน้าที่ต้องการ พร้อมดูภาพตัวอย่างสด
- **จัดเรียงและลบหน้า (Organize PDF):** ดูภาพพรีวิวทุกหน้า สลับลำดับหน้า ลบหน้าที่ไม่ต้องการ หรือหมุนแต่ละหน้าได้อย่างอิสระ

### 2. แปลงไฟล์ (Convert)
- **PDF เป็นรูปภาพ (PDF to JPG / PNG):** แปลงทุกหน้าของ PDF เป็นภาพความละเอียดสูง (150 DPI / 300 DPI) ดาวน์โหลดแยกภาพหรือดาวน์โหลดเป็น ZIP ได้
- **รูปภาพเป็น PDF (Images to PDF):** นำรูปภาพ JPG, PNG, WebP มาแปลงเป็น PDF จัดเรียงลำดับ ปรับขนาดกระดาษ (A4, Fit, Letter) และปรับขอบกระดาษได้
- **PDF เป็น Word (.docx) & ข้อความ:** สกัดข้อความจากเอกสาร PDF และแปลงเป็นไฟล์ Microsoft Word (.docx) พร้อมเปิดแก้ไขและคัดลอกข้อความได้ทันที

### 3. บีบอัดและประหยัดพื้นที่ (Optimize)
- **บีบอัดไฟล์ PDF (Compress PDF):** ลดขนาดไฟล์ PDF เลือกระดับความแรงได้ 3 ระดับ (Extreme, Recommended, Low) แสดงขนาดไฟล์ก่อนและหลังการบีบอัด พร้อมคำนวณ % ที่ประหยัดได้

### 4. ตกแต่งและใส่สัญลักษณ์ (Security & Style)
- **ใส่ลายน้ำ (Watermark PDF):** พิมพ์ข้อความลายน้ำ (เช่น "สำเนาถูกต้อง", "CONFIDENTIAL", "DRAFT") ปรับความโปร่งแสง สี ขนาดตัวอักษร มุมเอียง และตำแหน่งได้
- **ใส่เลขหน้า (Page Numbers):** ใส่เลขหน้าอัตโนมัติ เลือกลำดับ รูปแบบ (เช่น "หน้า 1 จาก 10", "Page 1 of 10") และตำแหน่งที่ต้องการ

## 🛠 เทคโนโลยีที่ใช้ (Tech Stack)

- **Frontend Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS v4 + Lucide React (Icons)
- **PDF Engines:**
  - `pdf-lib`: รวม, แยก, หมุน, จัดระเบียบหน้า, ใส่ลายน้ำ, ใส่เลขหน้า
  - `pdfjs-dist`: แสดงตัวอย่างหน้าพรีวิว (Thumbnails), แปลง PDF เป็นภาพ Canvas, สกัดข้อความ
- **Office / Export:**
  - `docx`: แปลงข้อความเป็นเอกสาร Microsoft Word (.docx)
  - `jszip`: บีบอัดไฟล์สำหรับดาวน์โหลดชุดรูปภาพและไฟล์แยกหน้า
  - `canvas-confetti`: เพิ่มลูกเล่นฉลองเมื่อแปลงไฟล์สำเร็จ 🎉

## 💻 วิธีการเปิดใช้งาน (Getting Started)

```bash
# 1. เข้าสู่โฟลเดอร์โปรเจกต์
cd D:\Workspace\pdf-converter-web

# 2. ติดตั้งไลบรารี
pnpm install

# 3. รัน Development Server
pnpm dev

# หรือสร้างไฟล์ Production Build
pnpm build
pnpm preview
```

เปิดเว็บเบราว์เซอร์ไปที่: `http://localhost:5173`
